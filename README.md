# Bug Tracker 🐞

**Hi, and thanks for stopping by!** This is where every bug report, idea and question about the
[meanmail.dev](https://meanmail.dev) plugins for JetBrains IDEs comes together.

If something in a plugin is broken, confusing or simply missing — you are in the right place, and
your report is genuinely welcome. Every issue here is read by the developer, and most of them turn
into a fix.

## Before you open an issue

Two minutes here save a round-trip later:

1. **Update the plugin.** The bug may already be fixed in the latest version.
2. **Search [existing issues](../../issues?q=is%3Aissue).** If your problem is already there, a 👍 or
   a comment with your details helps more than a new issue.
3. **Have the details ready** — the template asks for the plugin version, the IDE version and the
   steps to reproduce.

<details>
<summary><b>Where do I find all that?</b> (click to expand)</summary>

<br>

- **Plugin version** — `Settings | Plugins | Installed`, shown next to the plugin name.
- **IDE version** — `Help | About`, then use **Copy and Close** and paste it into the issue.
- **Log file** — `Help | Show Log in Explorer` (**Finder** on macOS) opens the folder with
  `idea.log`. The last few dozen lines are usually enough.
- **Stack trace** — if the IDE showed a red error balloon, open it and copy the report text.

Please skim the log for anything private — file paths, host names, tokens — before attaching it.

</details>

A screenshot or a short screen recording is always welcome. And if you cannot fill in every field —
open the issue anyway; a partial report beats no report.

Issues are written in English so that every user can search and read them, but do not worry about
your grammar. It only has to be understandable, not perfect. 🌍

## Which plugins are covered?

All of them — everything published on the
[meanmail.dev vendor page](https://plugins.jetbrains.com/vendor/meanmail). Just pick yours from the
**Plugin Name** list in the template.

Each issue is automatically labelled with its plugin, so you can follow just the one you use — for
example [Pascal Flow](../../issues?q=is%3Aissue+label%3A%22Pascal+Flow%22) — or browse the
[full list of labels](../../labels).
