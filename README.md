# Bug Tracker

This repository is the public hub for bug reports, feature requests and questions about all
**meanmail.dev** plugins for JetBrains IDEs.

## Where to go

| I want to…                          | Where                                                                                |
|-------------------------------------|--------------------------------------------------------------------------------------|
| Report a bug                        | [New issue → Plugin Bug Report](../../issues/new?template=bug_report.yml)             |
| Suggest a feature                   | [New issue → Feature Request](../../issues/new?template=feature_request.yml)          |
| Ask for an Nginx directive          | [New issue → Request Nginx Directive Support](../../issues/new?template=directive_request.yml) |
| Ask a question or get help          | [Discussions](../../discussions)                                                      |
| Report a security vulnerability     | [Security advisory](../../security/advisories/new) — see [SECURITY.md](SECURITY.md)   |

## Before you report a bug

1. Update the plugin to the latest version — the problem may already be fixed.
2. Search [existing issues](../../issues?q=is%3Aissue) for a duplicate; add a 👍 or a comment instead
   of opening a new one.
3. Collect the details the template asks for:
   - **Plugin version** — `Settings | Plugins | Installed`, next to the plugin name.
   - **IDE version** — `Help | About` (use *Copy and Close*).
   - **Log or stack trace** — `Help | Show Log in Explorer` (Finder on macOS) → `idea.log`.
     Please remove private data (paths, tokens, hostnames) before attaching it.

Issues are written in English so that every user can search and read them.

## Plugins covered

Every plugin published on the
[meanmail.dev vendor page](https://plugins.jetbrains.com/vendor/meanmail) — pick yours in the
**Plugin Name** field of the issue template.

Each issue is labelled with the plugin it belongs to, so you can browse a single plugin, for example
[Pascal Flow](../../issues?q=is%3Aissue+label%3A%22Pascal+Flow%22), or open the
[full label list](../../labels).
